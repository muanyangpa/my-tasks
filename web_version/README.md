# My Tasks — 데스크톱 버전

루트의 모바일 폭 레이아웃을 데스크톱 전체 화면용으로 재구성한 버전입니다.
기능은 같고 공간 구성만 다릅니다.

```
open index.html
```

## 무엇을 바꿨나

### 문제

기존 레이아웃은 480px 카드를 화면 가운데 띄웁니다. 세로로 대시보드 → 필터 →
입력 → 검색 → 버튼이 쌓인 뒤에야 할 일 목록이 나옵니다. 데스크톱에서는
정작 보려던 목록이 500px쯤 아래에서 시작하고, 양옆은 빈 배경입니다.

카드 폭만 넓히는 것은 답이 아닙니다. 글줄이 늘어지고, 컨트롤이 의미 없이
가로로 늘어나며, 목록이 아래에 있다는 문제는 그대로입니다.

### 구조

읽는 것과 하는 것을 좌우로 나눴습니다.

- **왼쪽 레일 (290px)** — 상태를 보고 전환하는 곳. 제목, 전체 진행률, 필터, 단축키
- **오른쪽 본문** — 입력하고 목록을 보는 곳

둘은 각자 스크롤합니다. 할 일이 백 개여도 입력창과 진행률은 늘 같은 자리에 있습니다.

### 필터와 카테고리 통계를 합쳤다

기존에는 필터 알약(전체·업무·개인·공부)과 미니 진행률 바(업무 0/1, 개인 0/0…)가
**같은 세 카테고리에 대한 정보를 두 벌로** 보여줬습니다.

레일에서는 한 덩어리입니다. 각 행이 이름, 개수, 완료 바를 함께 들고 있습니다.
개수는 "누르면 몇 개가 보이는지", 바는 "그중 얼마나 끝났는지"입니다.
UI 요소는 줄고 정보는 늘었습니다.

### 그 외

- 본문은 880px에서 멈춥니다. 화면이 아무리 넓어도 글줄이 늘어지지 않습니다
- 드래그 손잡이와 삭제 버튼은 행에 마우스를 올릴 때만 보입니다. 목록이 조용해집니다
- 900px 아래에서는 한 단으로 돌아가고, 호버가 없는 터치 화면을 위해
  손잡이와 삭제 버튼을 다시 늘 보이게 합니다

### 그대로 둔 것

카테고리 색(업무 파랑 · 개인 초록 · 공부 보라), 다크 모드, 저장 형식, 단축키.
브리프는 레이아웃에 관한 것이지 앱의 정체성을 바꾸라는 것이 아니었습니다.

## 루트 버전과의 관계

두 버전은 각자 독립된 파일을 가집니다. 공유하지 않습니다.

`script.js`는 필터 구조가 달라진 네 군데만 다르고 나머지는 같습니다.
한쪽의 로직을 고치면 다른 쪽에도 옮겨야 합니다. 학습용 프로젝트라
단순함을 택했지만, 계속 쓸 것이라면 공통 로직을 한 파일로 빼는 편이 낫습니다.
